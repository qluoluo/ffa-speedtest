================================================================================

   - Auto-selects optimal BM_DOT based on G (group size)
   - Expected: 20-30% Stage1 improvement for G=3

✅ Optimization 3: FP16 o_buf
   - Uses FP16 for output buffer to reduce bandwidth
   - Expected: 5-10% total time improvement

✅ Optimization 4: Stage2 Compact
   - Only iterates over kept blocks in Stage2

✅ Optimization 5: Triton Autotune

================================================================================
🔍 Troubleshooting
================================================================================

Problem: Cannot import kernels
Solution: Make sure you're running from optimizations_v2/ directory
          and that the kernels/ subdirectory exists

Problem: CUDA out of memory
Solution: Reduce sequence length:
          python3 benchmarks/benchmark_all_opts.py --seq-len 131072

Problem: Triton compilation errors
Solution: Update triton: pip install --upgrade triton
          Clear cache: rm -rf ~/.triton/cache
